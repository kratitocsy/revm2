# Wynko ad set: 30 static creatives

On-brand static ads for Wynko (warm black and cream, orange accent, Sora). All copy comes from `marketing.html`.

- **Rendered PNGs:** `png/` (1080 px wide, ready to upload)
- **Overview:** `contact-sheet.png`
- **Source:** `ads.mjs` holds the copy and layout for each ad, `ads.css` holds the brand frame
- **Re-render:** `node marketing/ads/build.mjs` for all ads, or `node marketing/ads/build.mjs 07 12` for specific ones (needs Playwright). The build warns if any content spills out of its frame.
