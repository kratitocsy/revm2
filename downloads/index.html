Download Wynko

The desktop app and the browser extension work together. Install both for the strongest Focus Lock.

Wynko for Windows

Blocks distracting apps during your focus blocks and links your browser extension automatically.

Download for Windows If Windows shows a blue “protected your PC” screen, choose More info, then Run anyway. The installer isn’t code-signed yet. An older “revm2” install is removed for you.

Wynko Focus Lock extension

Blocks distracting sites and YouTube channels in Chrome, Edge and Brave. With the desktop app running, it links itself to your account.

Download extension
  1. Unzip the file somewhere you’ll keep it.
  2. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
  3. Click Load unpacked and pick the unzipped folder.
